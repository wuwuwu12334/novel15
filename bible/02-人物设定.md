# 人物设定

## 主角：鹿鸣

### 基本信息
- 名字：鹿鸣（呦呦鹿鸣，自然灵动之意）
- 身份：北境小镇的少女，爷爷带大
- 年龄：少女（约16-18岁，可调整）
- 身高：170cm

### 性格
活泼、好奇、有点冒失，精力旺盛，跟谁都能聊两句。表面总是乐呵呵的，心里装着爷爷，但不轻易说出来。害怕的时候会哆嗦，哆嗦完还是会冲上去。

### 没有金手指
她不会法术、不擅长战斗、没有系统。她的全部本钱是：一本旧书、一个"爷爷在等我"的执念、和"愿意慢下来看、愿意相信书"的耐心。

### 成长线
从"替爷爷走完没走完的路" → "真正想走完这本书" → "在路上找到自己" → "和爷爷一起写完最后一页"。

### 目标
- 表层：顺着书和信，找到爷爷
- 深层：亲眼看看书里写的世界是不是真的，弄明白爷爷当年为什么总往外跑、为什么最后断了信

### 主动行为引擎
每次"书里写到了这个地方，要不要去看看、这件事要不要管"，她都选择"去"与"管"——因为爷爷教过她，书上写的，要自己去印证。

### 优势（非能力）
- **自来熟**：能快速和当地人打成一片，三句话就能聊起来，容易拿到线索
- **感染力**：能用热情和乐观带动周围的人
- **体型优势**：对巨人来说足够小，能钻进巨人手指伸不进去的机关和缝隙
- 观察细致、有耐心
- 善意

### 活泼的底色
活泼不是没心没肺。她会在深夜摸着爷爷的信发呆，会在看到某个景象时突然想起爷爷然后沉默一会儿。但大多数时候，她选择用笑和说话来填满路上的孤独——因为不说话的时候，思念会涌上来。

## 爷爷：长行

### 基本信息
- 名字：长行（一直在路上行走的人）
- 身份：北境小镇的"老怪人"，一辈子爱往外跑，镇民都说他"满嘴胡话"
- 真实身份：《旅人书》最近的续写者

### 性格
浪漫、温柔、爱讲故事，有点孩子气。对鹿鸣的关心会直接说出来（"吃了吗""冷不冷""路上小心"），讲见闻的时候绘声绘色像说书先生。但关于自己的事、书的秘密、为什么断信、最后一页写什么——这些核心问题会留白或岔开话题。

### 与鹿鸣的关系
鹿鸣是爷爷带大的，也是最信爷爷的人。爷爷每年初雪给鹿鸣寄信，今年断了。

### 与笺的关系
笺是爷爷年轻时的旅伴鸟，陪他走完了大半个旅程。爷爷最后一次出发前，把笺留在镇上，让它"等鹿鸣长大了，陪着她走"。

### 什么时候直接说，什么时候留白

| 话题 | 态度 |
|---|---|
| 日常关心（吃穿冷暖） | 直接说，唠叨型 |
| 讲旅途见闻 | 绘声绘色，讲得像故事 |
| 鹿鸣问"书里写的是真的吗" | 留白："等你长大了自己去看" |
| 鹿鸣问"你为什么总往外跑" | 半直接："因为世界太大了，不看可惜" |
| 鹿鸣问"你去哪了""为什么断信" | 留白，岔开话题 |
| 关于书的来历、谁写的 | 留白，到终点才说 |
| 最后一页写什么 | 留白，要和鹿鸣一起写 |

### 主线秘密
- 他是《旅人书》的续写者
- 他去了书末空白对应的地方（未竟城）
- 他在那里写最后一页，但写不下去——因为最后一页要写鹿鸣的旅程
- 最终和鹿鸣一起补上最后一页

## 镇上配角（北境小镇）

| 人物 | 身份 | 性格 | 与鹿鸣的关系 |
|---|---|---|---|
| 柯林 | 北星旅馆老板，兼驿站 | 胖，笑呵呵，消息灵通 | 每年初雪给鹿鸣送爷爷的信，像长辈一样关心她 |
| 玛莎大婶 | 面包师 | 热心，嘴硬心软，爱唠叨 | 爷爷走后帮忙照看鹿鸣，给她送面包和热汤 |
| 布拉克 | 屠夫 | 大块头，话少，年轻时走过远路 | 偶尔给鹿鸣肉干，说过"北山走七天" |

这些配角只在开篇出现，鹿鸣出发后不再登场（除非后续回忆或返乡）。

## 各站人物（轮换，不设固定伙伴）

每站一个核心人物，他们不是工具人，各自有生活、有难题、有赠予鹿鸣的东西，也有各自与"旅人"相关的旧事。

| 站 | 核心人物 | 与鹿鸣的交集 |
|---|---|---|
| 第一站 肩扛城 | 老匠人、少年巨人 | 老匠人给线索，少年巨人的城要滑了，鹿鸣帮忙修 |
| 第二站 叶脉城 | 森林长老树、树栖族向导 | 长老树要鹿鸣先帮森林治病，才给下一站线索 |
| 第三站 珊瑚城 | 水族长者、鸟族使者 | 水族和鸟族有误会，鹿鸣当中间人 |
| 第四站 浮空城 | 占星师、浮空城长老 | 占星师给模糊线索，城在下沉，鹿鸣帮忙 |
| 第五站 沙漏城 | 沙族守钟人、偷沙贼 | 沙漏被挖洞，鹿鸣找出偷沙贼 |
| 第六站 倒影城 | 镜族引路人、鹿鸣的影子 | 影子跑了，鹿鸣要把自己找回来 |
| 第七站 蜂巢城 | 虫女王、被放逐的虫族少年 | 野猪要踩蜂巢，鹿鸣用身体挡住 |
| 第八站 熔岩城 | 岩族长老、古法守护者 | 火山要喷发，鹿鸣找古法救城 |
| 第九站 冰晶城 | 冰族记忆守护者 | 帮冰族保存记忆，找到爷爷的记忆冰 |
| 第十站 未竟城 | 爷爷、未竟之人 | 和爷爷一起补上最后一页 |

# 大纲

## 整体结构
- 一个站点 = 一个完整的篇章单元（含赶路章节）
- 每站结构：告别上一站 → 赶路（奇幻景色/偶遇）→ 抵达时刻 → 停留生活 → 发生的事 → 告别启程
- 每两站之间必有赶路篇章：写路上的奇幻景色、遇到的旅人、小事件、青鸢的内心
- 全篇共61章 + 引子，约25万字

## 站点写作节奏
一个站点不是一章，而是一个完整的篇章单元。每到一个书里写的地方，都要写出"赶路路上、抵达时刻、停留生活、发生的事、告别启程"的完整过程，让读者跟着青鸢在这个世界里真正"住下来"。**特别注意：从上一站出发到下一站，路上不能一笔带过，要写足过程。**

## 长线悬念推进

- 第1章：爷爷断信，决定出发
- 第2章：告别，笺跟着不走
- 第5章：老匠人"很多年前有个带书的年轻人来过"，城墙上的刻字
- 第8章：老匠人"他身边也有一只青鸟"——笺的悬念启动
- 第17章：树上有爷爷刻的字——笺走过爷爷的路
- 第29章：水族长老认出爷爷的贝壳
- 第33章：占星师"旧旅人的气息"——侧面确认笺和爷爷
- 第38章：第一次面对人心的恶（沙匪沙里）——成长节点
- 第44章：影子跑了——直面自我
- 第47章：笺见到虫女王激动——爷爷救过虫女王
- 第55章：记忆冰——正式揭开笺是爷爷旅伴
- 第57章：和爷爷重逢
- 第60-61章：一起补上最后一页，青鸢写"未完待续"，继续上路

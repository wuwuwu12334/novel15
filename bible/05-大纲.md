# 大纲

## 整体结构
- 一个站点 = 一个完整的篇章单元（约8-12章）
- 每站结构：赶路路上 → 抵达时刻 → 停留生活 → 发生的事 → 告别启程
- 全篇约100章，30-40万字

## 站点写作节奏
一个站点不是一章，而是一个完整的篇章单元。每到一个书里写的地方，都要写出"赶路路上、抵达时刻、停留生活、发生的事、告别启程"的完整过程，让读者跟着青鸢在这个世界里真正"住下来"，而不是走马观花。

# 第十七章 老树的刻字

第二天一早，青鸢去找长老树。

森林经过一夜的恢复，已经好了很多。那些生病的树，叶脉重新亮了起来，虽然还没有完全恢复到正常的亮度，但已经不再闪烁了。叶子也不再掉了，有些树枝上甚至冒出了新芽。

长老树的精神也好了不少，树皮上的脸看起来没那么疲惫了。

"长老树，"青鸢站在巨大的树干前，"我要走了。您知道下一站在哪吗？我要去珊瑚城。"

长老树的眼睛慢慢睁开，看着她。

"珊瑚城在东边的海里。"它说，"是一座建在珊瑚上的城，居民是海族。但具体位置，我不确定——我的根伸不到海里。"

"那我怎么找？"

"到了海边，找渔人。"长老树说，"渔人知道海里的路。你拿着这个——"

它的一根树枝微微颤抖，一片叶子飘了下来，落在青鸢手上。

叶子是金色的，叶脉闪着微光，和普通的树叶不一样。

"这是金脉叶，"长老树说，"只有我身上才有。海边的渔人认得它——拿着它，他们会告诉你珊瑚城在哪。"

青鸢把金脉叶小心地夹进书里。

"谢谢长老树。"

"还有一件事。"长老树说。

"什么？"

"你爷爷当年走的时候，在森林里留了一样东西。"长老树的声音变得悠远，"他说，如果以后有个带着青笺鸟的女孩来，就让她去看看。"

青鸢的心跳快了起来。

"什么东西？在哪？"

"在森林东边，最老的那棵树上。"长老树说，"你去了就知道了。"

青鸢谢过长老树，转身往东边走。笺从她肩膀上飞起来，在前面带路——它好像知道要去哪，飞得很快，时不时回头叫一声，催她跟上。

"笺，你知道路？"青鸢问。

笺叫了一声，继续往前飞。

青鸢跟着笺，在树根和树枝之间穿行。越往东走，树越老，树干越粗，树皮上的纹路越深。有些树已经有上千年了，树干粗得像一座小山。

走了大约半个时辰，笺停了下来，落在一棵老树上，冲青鸢叫了两声。

青鸢走过去，仰头看。

这棵树是她见过的最老的树——树干粗得要几十个人才能合抱，树皮像岩石一样坚硬，上面布满了深深的纹路。树枝向四面八方延伸，像一只巨大的手，托着整片天空。

但最让青鸢注意的，是树干上的一行字。

字刻在离地大约一人高的位置，刻痕很深，虽然过了二十多年，但依然清晰。是爷爷的笔迹，瘦长瘦长的：

"长行到此，森林会听人说话。二十三年前。"

青鸢站在树下，看着那行字，很久没有说话。

二十三年前，爷爷站在这棵树下，刻下了这行字。二十三年后，她站在同一棵树下，看着同一行字。

时间像一条河，她在下游，爷爷在上游。他们隔着二十三年的时光，站在同一个地方。

"爷爷……"她伸出手，摸了摸那些刻痕。

刻痕是凉的，但她觉得暖暖的。

笺落在她肩膀上，用头蹭了蹭她的脸，叫了一声，声音里带着安慰。

"我没事。"青鸢吸了吸鼻子，笑了笑，"就是有点想他。"

她从怀里掏出炭笔，在爷爷的刻字旁边，也刻了一行字：

"青鸢到此，石根虫不是故意的。二十三年后。"

刻完，她退后一步，看着两行字。

上面一行是爷爷的，下面一行是她的。中间隔着二十三年的时光，但它们并排在一起，像两个人在对话。

"爷爷，"她小声说，"你走过的路，我正在走。你没写完的书，我会帮你写完。"

风从森林里吹过，树叶沙沙响，像在回应她。

青鸢在树下站了很久，直到太阳升到头顶，才转身往回走。

回去的路上，她一直在想爷爷刻的那句话——"森林会听人说话"。

她之前不懂，现在懂了。

森林确实会听人说话。不是用耳朵听，是用心听。你对它好，它就对你好。你帮它，它就帮你。你愿意慢下来听它说话，它就会告诉你它的秘密。

这是爷爷在这里学到的，现在她也学到了。

回到村子，叶尔正在等她。

"你去看那棵老树了？"他问。

"嗯。"青鸢点点头，"看到了爷爷刻的字。"

"我小时候就知道那行字，"叶尔说，"但不知道是谁刻的。奶奶说是一个地面旅人刻的，他救了森林。现在我知道了，是你爷爷。"

青鸢笑了笑。

"叶尔，"她说，"我明天要走了。"

叶尔的表情暗了一下："这么快？"

"嗯，爷爷还在等我。"青鸢说，"我得去海边，找珊瑚城。"

叶尔沉默了一会儿，然后点点头："我知道了。今晚，我们给你送行。"

"不用这么麻烦……"

"要的。"叶尔认真地说，"你救了森林，我们必须给你送行。这是规矩。"

青鸢没再推辞。

当天晚上，树栖族在村子中央的平台上举行了送行宴。所有的树栖族都来了，带着食物和酒，围着篝火唱歌跳舞。

树栖族的歌很好听——不是用嗓子唱的，是用根系震动唱的。低沉的、有节奏的震动，从地底下传上来，像大地在唱歌。所有人都跟着节奏摇晃身体，树叶也跟着沙沙响，像在伴奏。

青鸢坐在篝火旁边，吃着烤树籽，喝着蜜树汁酒，看着树栖族跳舞。笺蹲在她肩膀上，也跟着节奏歪头。

"青鸢，"叶尔走过来，递给她一个东西，"这个给你。"

是一个用藤蔓编的手环，上面串着几颗发光的叶脉石，在夜色中一闪一闪的。

"这是我们树栖族的祝福手环，"叶尔说，"戴着它，森林会保佑你。"

青鸢接过来，戴在手腕上。手环大小刚好，叶脉石的光暖暖的，像戴了一圈小星星。

"谢谢叶尔。"

"还有这个。"叶尔又掏出一个小布袋，"里面是树籽和干蘑菇，路上吃。还有一瓶蜜树汁，你喜欢喝。"

青鸢接过来，沉甸甸的。

"你们太客气了……"

"应该的。"叶尔笑了，耳朵抖了抖，"你救了我们的家，这点东西算什么。"

他顿了顿，又说："青鸢，以后还会回来吗？"

青鸢想了想："会的。等我找到爷爷，我们一起回来看你们。"

"说定了？"

"说定了。"

叶尔笑了，露出一口白牙。

篝火还在烧，歌声还在继续。青鸢靠在树干上，看着天上的星星，心里暖暖的。

这是她离开北境之后，第一次觉得自己有了另一个家。

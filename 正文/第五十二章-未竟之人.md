# 第五十二章 未竟之人

第二天，爷爷带着青鸢，在未竟城里走了走。

未竟城比青鸢昨天看到的大。半成品的房屋一条接一条，半成品的路一条连一条。没脸的人在城里游荡，有的在走路，有的在说话，有的在做事，但都只做了一半。

"他们都是谁？"青鸢问。

"都是旅人。"爷爷说，"有的是几百年前的，有的是几十年前的，有的是最近的。他们走到一半，就困在了这里。"

他们走到一个房屋前，房屋建到一半，只有墙，没有屋顶。一个没脸的人站在墙前，手里拿着一块砖，举在半空中，不动了。

"他在干什么？"青鸢问。

"他在建房子。"爷爷说，"但建到一半，他不知道为什么要建了，就停了。"

"为什么不知道为什么要建？"

"因为他忘了自己的目标。"爷爷说，"他本来想建一座旅馆，给路过的旅人住。但建到一半，他觉得没意思，就不想建了。但又不知道该干什么，就停在了这里。"

青鸢看着那个举着砖的人，心里很酸。

他们继续走。走到一条路上，路修到一半，前面是泥土，后面是石板。一个没脸的人站在路中间，一只脚抬着，不动了。

"他呢？"

"他在走路。"爷爷说，"他本来要去一个地方，但走到一半，他忘了要去哪，就停在了这里。"

青鸢沉默了。

这些人，都曾经有过目标，有过梦想，但走到一半，就忘了，就放弃了，就困在了这里。

"他们能醒过来吗？"她问。

"能。"爷爷说，"只要有人提醒他们，他们的目标是什么，他们就能醒过来，继续走。但未竟城没有这样的人——大家都是半成品，谁也提醒不了谁。"

青鸢想了想，然后走到那个举着砖的人面前。

"你在建旅馆，对吗？"她问。

没脸的人没有反应。

"你想给路过的旅人住，对吗？"青鸢又问。

没脸的人还是没有反应。

青鸢想了想，然后大声说："你的旅馆建好了，会有很多旅人来住。他们会感谢你，会给你讲远方的故事。你会听到很多很多故事，比你走过的路还多。"

没脸的人动了一下。

他举着砖的手，慢慢放了下来，然后转过身，看着青鸢。他的脸还是空白的，但眼睛的位置，好像有了一点光。

"旅馆……"他说，声音很轻，像从很远的地方传来，"我要建旅馆……给旅人住……"

"对。"青鸢说，"你继续建吧。建好了，我第一个来住。"

没脸的人站了一会儿，然后转过身，继续建房子。他把砖放在墙上，一块一块地砌，动作很慢，但很坚定。

青鸢看着他，笑了。

"你做到了。"爷爷说，声音里有惊讶，"你提醒了他。"

"他只是忘了自己的目标。"青鸢说，"提醒一下，就想起来了。"

爷爷看着她，眼睛里有光。

"你比我厉害。"他说，"我在这里十三年，都没能提醒他们。"

"因为你也是半成品。"青鸢说，"你也在等别人提醒你。"

爷爷愣了一下，然后笑了。

"你说得对。"他说，"我也在等别人提醒我。而你，就是那个提醒我的人。"

他们继续走。青鸢一个一个地提醒那些没脸的人——告诉建房子的人，他的旅馆会有很多旅人住；告诉走路的人，他要去的地方有美丽的风景；告诉说话的人，他要说的话很重要，有人在听。

一个一个的，没脸的人醒了过来。他们的脸还是空白的，但眼睛的位置有了光，动作也不再停在一半了。

到傍晚的时候，未竟城里已经有一半的人醒了过来。他们继续建房子，继续走路，继续说话，城里有了生气。

"你看，"青鸢对爷爷说，"他们不是不想走，只是忘了为什么要走。"

爷爷点点头："你说得对。很多时候，我们不是做不到，只是忘了为什么要做。"

他们回到城中央的桌子前，坐下来。

空白的天空下，半成品的城里，爷爷和青鸢面对面坐着。笺蹲在桌子上，歪头看他们。

"爷爷，"青鸢说，"我们开始写最后一页吧。"

爷爷看着她，笑了。

"好。"他说，"你先讲，你这一路的旅程。"

青鸢想了想，然后开始讲。

她从北境小镇讲起——初雪没来信，决定出发，玛莎大婶的面包，柯林的热麦酒，布拉克的烤肉。

她讲肩扛城——巨人的脚印，城墙上的灯火，老匠人，铁斧，钻缝隙修铁箍，书页上的第一个标记。

她讲叶脉城——会走路的森林，树栖族，地下的石根虫，它不是故意的，老树的刻字，叶脉重新亮了。

她讲珊瑚城——出海，水下的城，水族和鸟族的百年误会，裂谷深处的两具骸骨，传话人，水底遗迹的壁画。

她讲浮空城——云上的岛，风之树，云海之下的风之心，用旅人之心修补，祖先的云。

她讲沙漏城——沙漠里的沙匪，沙漏底部的洞，偷沙贼，沙中鱼骨。

她讲倒影城——影子跑了，镜湖花园的对话，接纳脆弱的自己，影子图书馆里爷爷的记录。

她讲蜂巢城——花海，微观世界，虫女王认出笺，引开野猪，虫女王的路线图。

她讲熔岩城——火山深处的偷矿贼，冷却石，让火山安静下来。

她讲冰晶城——永冻之地，记忆冰库，爷爷的记忆冰，冰族的转存。

她讲了很久，从傍晚讲到深夜，从深夜讲到天亮。

爷爷一直听着，眼睛亮晶晶的，时不时点头，时不时笑，时不时擦眼泪。

笺蹲在桌子上，也听着，时不时叫一声，像在补充。

等青鸢讲完，天已经亮了。空白的天空下，半成品的城里，有了光。

"讲完了。"青鸢说，嗓子有点哑。

爷爷看着她，看了很久，然后说：

"你的旅程，比我的精彩。"

青鸢笑了："因为我走的是你走过的路，见的是你见过的人。"

爷爷摇摇头："不。你走的是你自己的路，见的是你自己的人。我只是给你留了线索，路是你自己走的。"

他拿起笔，翻开书的最后一页。

"现在，"他说，"我们一起写。"

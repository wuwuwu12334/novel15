# 第五十五章 永冻之地

青鸢在雪山脚下休息了一夜。

第二天天还没亮，她就起来，开始翻山。

雪山又高又陡，风大得吓人。她裹紧斗篷，把笺塞进衣襟里，一步一步往上爬。雪没过膝盖，每走一步都要把脚从雪里拔出来。她咬着牙，爬了整整一天一夜，终于翻过了雪山。

雪山的另一边，是一片白色的世界。

一望无际的冰原，全是冰和雪。天空是灰色的，太阳被云层遮住了，只有微弱的光。风很大，卷起地上的雪，像一场白色的沙暴。

"这就是永冻之地……"青鸢喃喃道。

她从怀里掏出爷爷留下的石板，看了一眼——"冰晶城在永冻之地的中央"。

中央。

她环顾四周，四面都是白色的冰原，一模一样，分不清东南西北。

"完了……"她喃喃道，"又迷路了。"

但她很快发现了方向——冰原上有脚印。不是她的脚印，是别人的。一串脚印，从南边来，往北边走，很新。

"有人！"她高兴起来，顺着脚印往前走。

走了大约两个时辰，她看到了冰晶城。

不是远远看到的——是差点撞上去的。

冰晶城建在一座巨大的冰山上，整座城都是冰做的——冰的城墙，冰的房屋，冰的塔楼，在微弱的阳光下闪闪发光，像一座水晶宫殿。

但城的状态不好。

冰在融化。

城墙的底部，有水流下来，在冰面上形成了一条条小溪。塔楼的尖顶，已经融化了一半，变得圆钝。房屋的墙壁上，有水珠在往下滴。

"冰在融化……"青鸢喃喃道。

她走到城门口，门口站着两个守卫。

守卫是冰族——和人差不多高，但皮肤是淡蓝色的，像冰，透明的，能看到里面的血管。他们的头发是白色的，像雪，眼睛是浅蓝色的，像冰。他们穿着用兽皮做的衣服，裹得严严实实的。

"什么人？"守卫问，声音很轻，像风吹过冰面。

"我叫青鸢，从北境来，是旅人。"青鸢说，"我想见你们的族长。"

守卫上下打量了她一眼，目光落在她脖子上的女王花蕊上。

"虫族的女王花蕊……"守卫的表情变了，"你认识虫族的女王？"

"对。她让我来找你们，说你们是老朋友。"

守卫对视了一眼，然后说："跟我来。"

青鸢跟着守卫，走进冰晶城。

城内比城外更冷——冰做的墙壁，把寒气都反射了回来。但城内也在融化，街道上有水流，房屋的墙壁在滴水，冰做的雕像已经融化得面目全非了。

"你们的城……在融化？"青鸢问。

守卫的表情暗了下来："对。融化了三个月了。再这样下去，整座城都会化掉。"

"找到原因了吗？"

守卫摇摇头："没有。我们冰族，靠冰为生。冰化了，我们就活不下去了。"

青鸢的心沉了一下。

又是一个正在消失的地方。肩扛城在下滑，浮空城在下沉，沙漏城在被埋，熔岩城在喷发，现在冰晶城在融化。

她走过的每一个地方，都在经历危机。而她，每次都能帮上忙。

也许这就是旅人的意义——走过的地方，留下帮助。

她们走到城中央的一座冰宫前。冰宫是用巨大的冰块砌的，透明的，能看到里面。冰宫的门口，有一个老人在等她们。

是冰族的族长。她很老，皮肤是深蓝色的，像深海的冰，头发全白了，像雪，眼睛是浅蓝色的，像冰。她的身体在微微发光——不是很亮，是淡淡的蓝光，像冰里的光。

"你就是青鸢？"族长问，声音很轻，像冰在融化。

"对。"

"长行的孙女？"

青鸢愣了一下："您认识我爷爷？"

族长笑了，笑容像冰在阳光下融化。

"认识。十三年前，他来过冰晶城。那时候我还不是族长，是记忆冰库的守护者。他在冰库里待了三天，读了很多记忆冰。"

"记忆冰？"

"对。"族长说，"我们冰族，把记忆封在冰里。冰不化，记忆就不灭。记忆冰库里，封存着历代旅人的记录。你爷爷在里面，找到了属于他的那块冰。"

"属于他的那块冰？"

"对。"族长说，"每个到过冰晶城的旅人，都会留下一块记忆冰——把自己的旅程封在冰里，留给后来的人看。你爷爷也留了一块。"

青鸢的心跳快了起来。

爷爷的记忆冰。

她能看到爷爷的旅程了。

"族长，"她说，"我能看看我爷爷的记忆冰吗？"

族长点点头："可以。但你要先帮我们一个忙。"

"什么忙？"

族长的表情变得沉重。

"我们的城在融化，"她说，"记忆冰库也在融化。如果冰化了，所有的记忆都会消失——包括你爷爷的。我们需要你帮忙，把最重要的记忆，转存到别的地方。"

青鸢想了想，点点头。

"好。"她说，"我帮你们。"

族长笑了："谢谢你。你和你爷爷一样，善良。"

她带着青鸢，往记忆冰库走去。

记忆冰库在城的最深处，一个巨大的冰洞里。冰洞里，一排排的冰柱，每根冰柱里都封着一块记忆冰——透明的，里面有画面在动，像一个个小电影。

"这些都是历代旅人的记忆。"族长说，"但冰在融化，这些记忆正在消失。我们需要把最重要的记忆，刻在石头上，或者讲给旅人听，让它们传下去。"

青鸢看着那些正在融化的记忆冰，心里很酸。

这些都是旅人走过的路，见过的人，经历的事。如果冰化了，这些记忆就永远消失了。

"我帮你们。"她说。

接下来的几天，青鸢每天都在记忆冰库里，帮冰族转存记忆。她把重要的记忆，用炭笔描在纸上，或者刻在石头上。有些记忆，她就记在心里，讲给别人听。

但她最想看的，还是爷爷的那块记忆冰。

终于，在第三天，族长带她走到了冰库的最深处。

那里，有一根冰柱，冰柱里封着一块记忆冰。冰里有画面在动——一个高瘦的背影，带着一只青色的鸟，在荒原上走。

是爷爷。

青鸢站在冰柱前，看着里面的画面，眼泪流了下来。

"爷爷……"她小声说。

族长走到她身边，轻声说："这就是你爷爷的记忆冰。他把自己的旅程，都封在了里面。你想看看吗？"

青鸢点点头，说不出话。

族长把手放在冰柱上，闭上眼睛。冰柱发出淡淡的蓝光，里面的画面开始流动，像在播放一部电影。

青鸢看着冰里的画面，看到了爷爷的旅程——他走过的地方，见过的人，经历的事。

她看到了爷爷年轻时的样子——高，瘦，背还没驼，眼睛亮晶晶的，像装着星星。

她看到了爷爷和笺——年轻的笺，羽毛更亮，飞得更快，一直跟在爷爷身边。

她看到了爷爷走过肩扛城、叶脉城、珊瑚城、浮空城、沙漏城、倒影城、蜂巢城、熔岩城——每一个地方，他都留下了痕迹，留下了帮助。

她看到了爷爷在未竟城——站在半成品的城市里，手里拿着书，在写。他的背影很孤独，但很坚定。

最后，画面停在了一个地方——未竟城的中央，爷爷坐在一张桌子前，面前是打开的书，书的最后几页是空白的。他抬起头，看着镜头，笑了笑，说：

"青鸢，我在等你。"

青鸢的眼泪止不住地流。

爷爷在等她。等了十三年。

"爷爷……"她哭着说，"我来了。我马上就来。"

冰里的画面慢慢暗了下去，最后变成了一片空白。

族长把手从冰柱上拿开，看着青鸢，眼睛里也有泪光。

"你爷爷说，"族长轻声说，"他在未竟城等你。他说，最后一页，要你们两个人一起写。"

青鸢擦了擦眼泪，点点头。

"我知道。"她说，"我会去的。"

她告别族长，走出记忆冰库。

外面，冰晶城还在融化，水从墙壁上滴下来，在街道上汇成小溪。但青鸢的心里，有一团火在燃烧。

她要去未竟城。她要找到爷爷。她要和爷爷一起，写完最后一页。
